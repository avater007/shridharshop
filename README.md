# 🛒 ShridharShop – Amazon Clone

ShridharShop is an Amazon-inspired e-commerce website developed to provide a simple, modern, and user-friendly online shopping experience. This project demonstrates my frontend web development skills and practical knowledge of UI/UX design.

## 🚀 Features

- Modern and responsive user interface
- Amazon-inspired homepage design
- Product listing and display
- Navigation bar
- Search functionality
- Shopping cart interface
- User-friendly layout
- Attractive styling and design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
